# Personal Portfolio Website

## Project Overview

This project is a responsive personal portfolio website created for the Week 2 Web Development task at **DG Interns Hub**. It presents my profile and portfolio information in a single webpage and uses **HTML5** for structure, **CSS3** for styling and layout, and **JavaScript** for interactive behavior.

The website includes Home, About, Skills, Education, Projects, and Contact sections. The design uses a dark background, blue and purple accent colors, responsive layouts, cards, and animations to make the content easier to navigate and read.

## Features

- **Home section:** Introduction, animated role text, profile image, action buttons, and social links.
- **About section:** Personal introduction and background information.
- **Skills section:** Skills displayed in card layouts.
- **Education section:** Academic details organized in a table.
- **Projects section:** Project information presented in project cards.
- **Contact section:** Contact form with required-field and email input validation.
- **Responsive navigation:** Mobile menu toggle, menu closing after navigation, Escape-key support, and menu reset on wider screens.
- **Typing animation:** Cycles through Web Developer, Software Developer, and Python Developer.
- **Scroll reveal effects:** Selected content appears as the visitor scrolls.
- **Active navigation:** Highlights the navigation link for the current section.
- **Back-to-top button:** Appears after scrolling and returns the visitor to the top.
- **Automatic copyright year:** JavaScript updates the displayed year.
- **Accessibility considerations:** Includes navigation labels and reduced-motion handling.

> **Contact form note:** The form currently performs front-end validation only. It does not send or store messages. A backend or email service must be connected to enable message delivery.

## Technologies and Tools

- **HTML5** — webpage structure and content.
- **CSS3** — colors, typography, spacing, Flexbox/Grid layouts, hover states, responsive styling, and animations.
- **JavaScript** — mobile navigation, typing animation, scroll reveal, active navigation, back-to-top behavior, form validation, and copyright year.
- **Visual Studio Code** — editing project files.
- **Google Chrome** — running and testing the webpage.
- **Live Server** — local development server; the included VS Code settings specify port `5501`.

## How to Run the Project

1. Download or extract the project folder.
2. Open the folder in Visual Studio Code.
3. Confirm that `index.html`, `css/style.css`, `js/script.js`, and the profile image are present.
4. Open `index.html` in a browser, or run it using the Live Server extension in Visual Studio Code.
5. If using Live Server, the included settings configure port `5501`.
6. Test the navigation, responsive menu, typing animation, scrolling effects, back-to-top button, and contact form validation.

## Learning Objectives

The Week 2 task builds on HTML fundamentals by applying CSS and JavaScript to a portfolio website. The work demonstrates:

- Styling webpage elements with colors, fonts, spacing, borders, and visual effects.
- Arranging content with CSS Grid and Flexbox.
- Using media queries and responsive layout rules for different screen sizes.
- Responding to clicks, keyboard input, scrolling, and form submission with JavaScript event listeners.
- Selecting and updating HTML elements through the DOM.
- Testing and organizing frontend files in a project folder.

## Notes

- External links and social profile URLs should be checked before publishing the site.
